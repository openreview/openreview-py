# Official Comment

Official Comment is the paper-specific communication action. JMLR uses
this existing action for communication among authors, reviewers, Action
Editors, and Editors-in-Chief.

## Uses

| Sender | Purpose |
| --- | --- |
| Author | Ask paper-specific questions, provide clarification, or summarize changes made for an accepted paper with minor revision. |
| Reviewer | Ask the handling Action Editor a restricted review-stage question. |
| Action Editor or Editor-in-Chief | Send editorial guidance, including camera-ready corrections, to selected paper participants. |

System-generated workflow notifications remain email messages. Official
Comment owns participant-authored communication recorded on the paper forum.

## Readers And Notifications

- Editors-in-Chief remain readers of every restricted Official
  Comment.
- The sender selects the other permitted paper groups that should read the
  comment. OpenReview notifies the selected readers after submission.
- An author writing to the handling editor should select the paper Authors and
  paper Action Editors. The author should not select Reviewers or public
  readers.
- A reviewer writing to the handling editor should select the paper Action
  Editors and keep Authors and peer Reviewers unselected.
- A camera-ready correction request from an Action Editor should select the
  paper Authors and paper Action Editors.
- Reader selections must not expose reviewer identities to authors or peer
  reviewers. Unrelated users and Production Editors must not receive restricted
  editorial communication.

Official Comments are optional communication records. They do not create
pending tasks or replace required review, decision, camera-ready upload, or
camera-ready verification actions.
