# Action Editors

## Your Work

- Manage assigned papers from review start through decision and camera-ready verification.
- Assign and manage reviewers.
- Monitor review progress and the paper's review due date.
- Submit decisions and rate reviewers.
- Check resubmission history, author-list differences, and reviewer continuity for papers you handle.
- Regular and public managed tracks are assignment-eligibility classifications on the same Action Editor workflow. OSS and Award are the initial managed tracks.

## Where To Go

Use the Action Editor Console for pending tasks, assigned papers, assignment availability, and expertise. Open papers from that console to keep the AE role context.

Assignment availability is global across all tracks. Track eligibility is
managed by Editors-in-Chief and is public as part of JMLR's editorial-board
listing; availability remains private. See
[Action Editor Membership And Track Eligibility](../workflow/action-editor-eligibility.md).

Ordinary candidate selection may account for Action Editor load. JMLR does not
add a second load or quota gate; it adds only the documented membership,
continuity, and track-eligibility rules to the standard assignment surface.

## Main Actions

| Action | When to use it |
|---|---|
| Assign Reviewers | Open the paper-specific reviewer assignment page and add enough eligible reviewers for an assigned paper. |
| Review Approval | After assignment, select `Appropriate for Review` to start the normal reviewer-assignment workflow, or `Desk Reject` to request EIC desk-rejection approval. |
| Reviewer assignment controls | Adjust reviewer assignments and set the due date for newly assigned reviewers from the assignment page while the paper state allows it. |
| Reviewer removal | Remove an assigned reviewer who has not submitted a review from the assignment page when reviewer management is still allowed. |
| Official Comment | Send paper communication to selected permitted readers. |
| Decision | Submit an editorial decision after the review threshold is met: 2 reviews for a first submission in any track, or 1 review for a linked resubmission. |
| Reviewer Rating | Submit the required `Exceeds expectations`, `Meets expectations`, or `Falls below expectations` value when the Rating action is available. |
| Verify camera-ready revision | Check the latest final material and approve it. If correction is needed, post a restricted Official Comment to the authors and wait for a corrected upload. |

## Notes

Use Review Approval for the initial suitability check after AE assignment.
`Desk Reject` starts the EIC approval path; it is not the later Decision
form or the direct pre-AE EIC Desk Rejection. Automatic approval may complete
the standard EIC task when configured, but the AE must always originate the
recommendation through the rendered Review Approval form. Use the normal
Decision action for an editorial outcome after the applicable review threshold
is met.

The review form records structured reviewer assessments but no editorial
recommendation. Editorial outcomes belong to the later Decision action.

On the Assign Reviewers page, set the review due date when assigning reviewers
through previous-reviewer, auto-assign, search, or external-invite flows.
Existing reviewer due dates are not edited from the paper forum.

Official Comments should use the visible paper action and should only be
readable by the roles selected by the form and allowed by the paper state.

If you also hold another role, enter papers from the Action Editor Console when acting as AE. AE actions should use the assigned AE role context for that paper.

For resubmissions, check previous-submission links and author-name differences
as editorial context. The same Review Approval task applies to initial
and continuity assignments; JMLR does not add another resubmission-specific
approval task.

Linked resubmissions may show profile-safe names for immediately previous
reviewers as assignment context. Current-round anonymous reviewer ids are fresh;
the context does not create stable cross-round reviewer identities or assign
any previous reviewer.
