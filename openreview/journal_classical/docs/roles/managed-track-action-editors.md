# Managed-Track Action Editors

JMLR uses one `JMLR/Action_Editors` role. A public eligibility edge records
which managed tracks an Action Editor may handle; it does not create a separate
role group or console.

Use [Action Editors](action-editors.md) for the shared assignment, availability,
load, and decision workflow. Editors-in-Chief manage track eligibility from the
focused Action Editor management page.
