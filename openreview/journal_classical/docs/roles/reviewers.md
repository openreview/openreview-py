# Reviewers

## Your Work

- Review assigned JMLR papers.
- Keep your assignment availability and maximum active review load current.
- Submit the complete review from the paper's Review form.
- Use paper-specific contact with the Action Editor when review-stage questions arise.

## Where To Go

Use the Reviewer Console for pending reviews, assigned papers, availability, and expertise. Open papers from that console to stay in reviewer role context.

## Main Actions

| Action | When to use it |
|---|---|
| Submit Review | Complete the contribution summary, strengths and weaknesses, requested changes, broader-impact concerns, claims-and-evidence assessment, and audience assessment. |
| Edit/Read Review | Reopen your submitted review when the paper state allows it. |
| Official Comment | Ask the handling editor a restricted paper-specific question by selecting the paper Action Editors and leaving Authors and peer Reviewers unselected. |
| Assignment Availability | Pause or resume new reviewer assignments. |
| Max Active Reviews | Set your preferred active review load. |
| Top Reviewer Listing | Choose whether to be listed on the website if you qualify for Top Reviewer recognition. |

## Notes

The current review form has no recommendation field and no review-file upload.
Editorial outcomes belong to the later Decision action.

Authors can read each submitted review immediately, while peer reviewers see it
after the configured review-release threshold. Review content remains anonymous
to authors and peer reviewers.

If you also hold another JMLR role, enter papers from the Reviewer Console when acting as reviewer. The reviewer page should not offer AE, EIC, production-editor, or author signatures.

Top Reviewer listing is website recognition only. Choosing the opt-out setting does not affect review assignments, availability, load, conflicts, or reviewer permissions.

Reviewer recruitment is described in
[Role Recruitment](../workflow/role-recruitment.md).
